Sparse GE and DFS-Reorder — apple-to-apple comparison

PPVH erasure decoder (arXiv:2208.01002). 1000 trials per erasure rate, fixed RNG seed so all three conditions decode the identical erasure/error samples.

Charts compare Sparse vs Sparse + DFS (Dense is omitted from the charts so the y-axis zooms into the sparse range; Dense remains in the summary table as the GE-time speedup baseline). Because the seed is fixed, all conditions decode identical samples, so the failure-rate curves coincide except where DFS picks a different minimum-weight solution. GE time is elimination only — the DFS reordering cost is measured separately and shown in its own chart and the summary table, so it is excluded from the GE-time comparison. Times in milliseconds (GE/reorder are totals over all trials; decode time is the per-trial average).
